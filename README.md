# WanderLust Adventures — Travel Agency Landing Page

A modern, fully responsive, single-page website for a travel company called **WanderLust Adventures**. Designed to showcase vacation packages, travel services, customer stories, and booking options with smooth CSS animations and modern visual elements.

---

## Features

* **Fully Responsive Design:** Adapts smoothly across mobile, tablet, and desktop viewports.
* **Modern UI Elements:** Glassmorphism, card shadows, hover zoom effects, and custom CSS floating animations.
* **Navigation Bar:** Fixed-top navigation with smooth scrolling to key sections.
* **Hero & Booking Widget:** Catchy slogan, hero promo section, and quick search form.
* **Featured Destinations:** Interactive cards featuring trip ratings, duration, and prices.
* **User Stories & Testimonials:** Real customer feedback card grid.
* **Contact & Footer:** Functional contact form, company details, and newsletter signup.

---

## Technical Details

* **Built With:** HTML5, CSS3, Bootstrap 5, and Bootstrap Icons.
* **Effects:** Custom CSS keyframe floating animations, smooth scrolling, and hover effects on cards.
* **Browser Compatibility:** Works in any standard web browser (Chrome, Safari, Edge, Firefox) without needing a local server or extra installation.

---

## AI Disclosure & Methodology

* **AI Model / LLM Used:** Google Gemini
* **Developer:** Google
* **Tasks Performed:** Generated the site structure, responsive Bootstrap layout, custom CSS keyframe animations, promotional text, and user stories.
